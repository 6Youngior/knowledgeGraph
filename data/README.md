# 数据说明

数据围绕大模型与算力产业，包含 DeepSeek-R1、Qwen3、GLM-5、MiniMax-M2.5 等主题，以及芯片、服务器和相关上市公司的财报资料。

## 文件与规模

| 文件 | 内容 |
|---|---|
| `knowledge_graph.json` | 112 个实体、128 条关系、10 个事件 |
| `sources.json` | 56 条图谱证据来源，含财报页码与原文 |
| `corpus/` | 40 家公司、168 份去重财报的目录与开发抽取审核记录 |
| `finance/` | 5 家公司的财务、主营构成与行情样本 |
| `quant/` | 38 只 A 股的行情来源目录、Qlib 基线预测与三组模拟回测 |
| `history/` | 历史资料的固定版本、日期依据与回放适用范围 |
| `extraction_samples.json` | 4 篇可重复导入的抽取回放样例 |
| `extraction_eval.json` | 期中抽取初试材料，保留用于错例回顾，不作为当前评测答案 |

| `raw/` | 腾讯财经原始响应，用于离线重建行情 |
| `neo4j/import.cypher` | 期中图谱的 Cypher 导出；当前运行使用 NetworkX |

初始事件图谱由人工整理；后续财报关系经过模型抽取、原文定位和语义审核。原始财报数量与图谱引用的段落数量分别统计，整批语料尚未全部入图。

## 实体与关系

| 实体类型 | 数量 | 示例 |
|---|---:|---|
| Company | 21 | 智谱、海光信息、寒武纪、中芯国际 |
| Stock | 8 | 02513.HK、09988.HK、688795.SH |
| Model | 9 | 4 个主题及相关版本 |
| Product | 48 | MTT S5000、阿里云百炼、芯片板卡与服务产品 |
| Industry | 16 | 模型、云服务、集成电路等分类 |
| Event | 10 | 模型发布、技术适配、云服务接入 |

八类关系为 `DEVELOPED_BY`、`LISTED_AS`、`PRODUCES`、`SUPPORTS_MODEL`、`HOSTS_MODEL`、`RELEASED_MODEL`、`CONCERNS` 和 `BELONGS_TO`。

每条关系保存来源 ID、原文片段和日期。`PRODUCES` 表示公司提供硬件、平台或服务产品；`SUPPORTS_MODEL` 表示硬件适配，`HOSTS_MODEL` 表示云推理服务接入。行业分类不参与关联证券查询。

## 来源日期

核实发布日期后填写 `published_at`；动态文档的发布日期无法核实时留空，另记 `retrieved_at`。历史查询检查路径上每条关系的来源日期，后补材料不用于更早的查询。上市日期和上市文件公开日期分别记录。

MCP 同时检查正文版本、证据和关系在研究日是否可用。普通网页的当前正文不能按页面最初发布日期回填；固定财报按对应披露日处理。Web 日期筛选及旧事件收益展示尚不代表完整的历史预测评估。

来源只保存课程研究所需的短摘录，完整内容以原始链接为准；省略部分以“……”标出。部分公司采用集团或品牌的研究粒度，业务单位到上市集团的层级映射尚待补充。

## 增量样例与抽取核对

GLM-5 的 MTT S5000 适配事实从初始图谱留出。导入固定回放后，增加 1 个适配事件和 3 条关系；关联证券由 2 只变为 3 只，新增摩尔线程。已有产品、公司和证券节点不重复创建。其余 3 篇回放用于类型、实体对齐与重复导入检查，界面均明确标注回放模式。

期中 6 段抽取初试含有组织名称标注问题，旧汇总评分不复用。当前首轮财报抽取审核了 12 段开发文本，采用 22 条关系证据，其中 1 条补充已有关系。正式实验将另建独立标注集，分别评估实体链接与关系抽取。

随后补充 72 份 2023 年原始披露，并从 8 段开发文本采用 29 条历史关系证据，新增 22 条事实。审核记录与资料日期见 [corpus/](corpus/)。历史资料尚未覆盖全部研究关系，图谱特征还没有进入量化模型。
