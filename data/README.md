# 数据说明

当前数据围绕 DeepSeek-R1、Qwen3、GLM-5、MiniMax-M2.5 四个主题，包含 10 个发布、适配和接入事件。研究对象限定在相关的 A 股、港股公司。

## 文件与规模

| 文件 | 内容 |
|---|---|
| `knowledge_graph.json` | 59 个实体、85 条关系的初始图谱 |
| `sources.json` | 41 条来源的链接、发布方、日期与原文短摘录 |
| `extraction_samples.json` | 4 篇可重复导入的抽取回放样例 |
| `extraction_eval.json` | 6 段真实文本及指定目标关系；Qwen3 研发主体参考待复核 |
| `market/*.csv` | 8 只股票与 2 条基准的真实日线，共 2448 行 |
| `raw/` | 腾讯财经原始响应，用于离线重建行情 |
| `neo4j/import.cypher` | 图谱的 Cypher 导出；原型实际使用 NetworkX |

来源中有 33 条官方、公司及交易所资料，8 条媒体报道。主要产业事件为 2025.01—2026.02；证券映射还使用了更早的上市文件。初始图谱由人工整理并核对来源。

## 实体与关系

| 实体类型 | 数量 | 示例 |
|---|---:|---|
| Company | 9 | 智谱、阿里巴巴、摩尔线程 |
| Stock | 8 | 02513.HK、09988.HK、688795.SH |
| Model | 9 | 4 个主题及相关版本 |
| Product | 16 | MTT S5000、阿里云百炼 |
| Industry | 7 | 模型、云服务、芯片等分类 |
| Event | 10 | 模型发布、技术适配、云服务接入 |

八类关系为 `DEVELOPED_BY`、`LISTED_AS`、`PRODUCES`、`SUPPORTS_MODEL`、`HOSTS_MODEL`、`RELEASED_MODEL`、`CONCERNS` 和 `BELONGS_TO`。

每条关系保存来源 ID、原文片段和日期。`PRODUCES` 表示公司提供硬件或平台产品；`SUPPORTS_MODEL` 表示硬件适配，`HOSTS_MODEL` 表示云推理服务接入。行业分类不参与关联证券查询。

## 来源日期

核实发布日期后填写 `published_at`；动态文档的发布日期无法核实时留空，另记 `retrieved_at`。历史查询检查路径上每条关系的来源日期，后补材料不用于更早的查询。上市日期和上市文件公开日期分别记录。

例如，本次资料下 DeepSeek-R1 在 2025-01-20、02-03、02-05 的关联证券数为 0、2、4。Qwen3 发布时摩尔线程尚未上市，因此没有当时的股票行情窗口。日期处理的具体说明见 [SOURCE_NOTES.md](SOURCE_NOTES.md)。

来源只保存课程研究所需的短摘录，完整内容以原始链接为准；省略部分以“……”标出。部分公司采用集团或品牌的研究粒度，业务单位到上市集团的层级映射尚待补充。

## 增量样例与抽取核对

GLM-5 的 MTT S5000 适配事实从初始图谱留出。导入固定回放后，增加 1 个适配事件和 3 条关系；关联证券由 2 只变为 3 只，新增摩尔线程。已有产品、公司和证券节点不重复创建。其余 3 篇回放用于类型、实体对齐与重复导入检查，界面均明确标注回放模式。

抽取预实验实际调用模型核对 6 段文本：5 条目标关系精确匹配 4 条，共同提及负例没有生成目标关系。实体目录已提供给模型，当前规模不足以评估总体性能；逐例说明见 [EXTRACTION_PILOT.md](../docs/EXTRACTION_PILOT.md)。

## 重建

```powershell
python data/build_dataset.py           # 读取原始行情缓存，不联网
python code/audit_data.py
python code/export_neo4j.py
```

`python data/build_dataset.py --refresh` 可重新下载行情；事件资料与原文摘录仍使用随附的已整理数据。
