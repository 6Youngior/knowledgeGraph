# 财报语料

当前目录记录 40 家公司的 96 份去重年报与中报，范围以 [universe.json](../universe.json) 为准。每份文档保留官方链接、证券代码、发布日期、采集日期、PDF 与解析正文的 SHA-256。

| 文件 | 内容 |
|---|---|
| `documents.jsonl` | 每行一份完整财报的元数据 |
| `manifest.json` | 去重文档、页数、片段和版本数量及目录哈希 |
| `extraction_review.json` | 首轮 12 段开发样本的抽取审核记录 |

PDF 与解析全文保存在本地缓存，不放入 Git。当前共解析 20,191 页、切分 34,669 个片段；这些片段不计作独立文档。96 份财报来自多批采集，其中包括 2 份修订版，以及 2 份尚未核实初始公开版本的港股报告快照。

图谱目前只采用了部分主营业务段落。首轮审核纳入 22 条关系证据，其中 1 条为已有关系补充来源；这批材料用于开发与错例分析，没有用于报告抽取准确率。

采集、解析与审核入图命令见[开发说明](../../docs/DEVELOPMENT.md)。
