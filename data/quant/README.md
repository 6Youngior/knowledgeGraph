# AI 股票量价基线

这轮实验先建立可以重跑的量化对照，尚未加入知识图谱特征。特征、训练和交易模拟使用 Qlib 0.9.7，模型为 LightGBM 4.7.0；Agent 负责调用结果和解释数据。

## 数据

股票池取自 [universe.json](../universe.json) 中的 38 家 A 股公司，包括芯片、服务器、光互联、数据中心等方向。行情覆盖 2021-01-04 至 2026-11-12，新上市公司从实际有报价的日期开始。共 49,814 个股票交易日观测，沪深 300 为 1,419 个交易日。

每只股票保留原始和前复权两套价格，二者不重复计数。`market_manifest.json` 保存 77 个数据文件的来源、采集时间、行数与 SHA-256。完整 CSV 和原始响应保存在本地 `.fingraph/market/ai-a-share/`；采集命令见[开发说明](../../docs/DEVELOPMENT.md)。后续重新采集的复权快照可能发生变化，应同时核对哈希与结果日期。

## 设置

| 项目 | 本轮设置 |
|---|---|
| 特征与模型 | Qlib Alpha158，LightGBM；种子 1729，最多 120 轮，验证集提前停止 |
| 训练特征日 | 2021-05-07—2024-12-23 |
| 验证特征日 | 2025-01-02—2025-12-23 |
| 测试特征日 | 2026-01-05—2026-11-04 |
| 标签 | 特征日 t 之后，t+1 收盘至 t+6 收盘的前复权收益 |
| 分段处理 | 每段末尾剔除无法在本段内完整观察标签的六个交易日 |
| 组合 | 前八名，每五个交易日决策；Qlib TopkDropoutStrategy |
| 对照 | 相同股票池等权、20 日动量前八名、沪深 300 指数 |
| 成交与费用 | 次日收盘成交；资金 100 万元，目标仓位 95%，按 100 股交易单位取整；买卖各千分之一，单笔最低 5 元 |

三组组合使用相同回测日期、初始资金和费用。等权组合复用 Qlib 的 WeightStrategyBase；动量组合沿用模型组合的持仓及换仓规则。持有期间缺失交易日不压缩日历，入场和出场缺报价的标签不参与评分。

## 当前结果

回测区间为 2026-01-06—2026-11-11，共 205 个交易日；净值按收盘市值计算，期末未强制平仓。Qlib 需要下一日的日历边界，因此最后一个行情日用于封闭回测区间。结果文件的最新模型排序使用 2026-11-12 特征，与回测区间分开记录。

| 组合 | 区间收益 | 最大回撤 |
|---|---:|---:|
| Alpha158 / LightGBM | 16.81% | -41.90% |
| 同池等权 | -2.80% | -34.40% |
| 20 日动量 | 10.41% | -47.30% |
| 沪深 300 | -14.92% | — |

前三行已扣除上述模拟费用，指数收益不包含组合交易成本。7,630 条有效测试预测的平均 IC 为 -0.0059，平均 Rank IC 为 0.0037。排序指标接近零，单一区间的正收益不能说明模型已具备可靠的选股能力。

收益对区间端点较敏感：最后一日组合净收益为 10.44%，此前累计收益为 5.77%。这也需要在观察整段曲线时一起考虑，不能只比较期末收益。

股票池按当前 AI 公司选择，存在事后选池偏差；价格为当前复权快照，没有重建历史涨跌停和 ST 状态，成交模拟也未包含流动性冲击。当前图谱在训练区间没有可用的历史关系，因此没有把后采集的关系回填为训练特征。下一轮先补历史披露，再比较量价、行业特征和图谱特征。

## 文件

| 文件 | 内容 |
|---|---|
| `baseline.json` | 实验日期、模型、划分、行情哈希、指标、全量净值及最新排序 |
| `test_predictions.csv` | 留出测试区间的模型分数与五日收益标签 |
| `daily_ic.csv` | 逐交易日 IC 与 Rank IC |
| `backtest*.csv` | 三组组合的账户、收益、换手、费用和现金记录 |
| `market_manifest.json` | 行情来源、单位、复权方式、采集时间和文件哈希 |

排序分数用于比较同日证券，不代表上涨概率或预期收益。终端和 Web 按实验结果的可用日读取文件，不会把这次训练结果提供给更早的研究日期。
