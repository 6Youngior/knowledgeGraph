# FinGraph 期中技术说明

## 研究任务

从一条模型产业消息出发，组织围绕该模型积累的跨源事实，找出有证据的上市公司关联、说明产业角色，并按研究时点审查证据。当前覆盖DeepSeek-R1、Qwen3、GLM-5、MiniMax-M2.5四个主题；关联结果不等同于原新闻直接提到的公司，也不等同于经济受益程度。

## 数据与显式表示

数据由官方发布、产品文档、公司新闻、交易所资料及具名媒体报道构成，另有真实行情缓存。种子图谱经过来源核对整理；LLM用于新资料的抽取、对齐与入图，不能将整个种子图谱描述成未经人工审查的全自动抓取结果。

| 实体 | 用途 |
|---|---|
| Model | 模型及版本 |
| Product | 硬件或云服务产品 |
| Company | 集团、品牌研究主体 |
| Stock | 具体证券代码、市场、币种与上市日 |
| Event | 带日期的发布、接入、适配消息 |
| Industry | 分类与候选审查，参与显示但不推导合作 |

每条边保留稳定ID、起点、关系类型、终点、原句、来源ID和披露日期。引用合并时保留逐来源的证据记录。企业研究实体采用有限的集团/品牌粒度，尚未完整建模集团、子公司和业务单位层级。

`PRODUCES` 表示公司提供产品：硬件场景包括生产，云场景包括平台提供；它不表示采购订单、制造合同或共同研发。证券上市有效日保存在证券属性中，与某份上市材料实际公开的日期分别处理。

## 知识抽取与更新

抽取器读取来源文本、允许的Schema和已知实体目录，输出JSON候选。目录用于类型与别名对齐，不能作为新事实证据。候选关系必须满足端点类型、来源存在、连续原句可定位和日期规则。云托管的HOSTS_MODEL与硬件适配的SUPPORTS_MODEL分开；不能由共同提及或同属行业补出合作关系。

这里的自动校验检查类型、日期和原句位置，不替代对来源真实性及关系含义的核查。例如“发布了某模型”不自动等于“研发了该模型”；新适配公告中没有证券代码时，需要连接已有产品、公司及交易所上市资料，不能把上市映射说成本句抽取结果。

候选先进入预览，确认后才修改图谱。自然事实键为 `(source, type, target)`，同一事实重复导入合并来源，不重复创建边。原始模型输出、实际模式和耗时保留；实时调用与固定已核验样例明确区分。GLM-5适配事实被留出用于可重复演示，导入时间不代表新闻首次出现时间。

## 关联查询

用NetworkX承载有向属性图，按明确允许的关系组合查询。事实方向与遍历方向分别记录：查询可以逆向经过产品关系，显示的箭头仍表示原事实。

| 角色 | 路径核心 |
|---|---|
| 直接研发 | Model → DEVELOPED_BY → Company → LISTED_AS → Stock |
| 硬件适配 | Model ← SUPPORTS_MODEL ← Product ← PRODUCES ← Company → LISTED_AS → Stock |
| 云服务接入 | Model ← HOSTS_MODEL ← Product ← PRODUCES ← Company → LISTED_AS → Stock |

事件节点通过RELEASED_MODEL或CONCERNS连接模型，产品事件可通过明确的CONCERNS找到其模型主题。同一证券的多个角色与路径分别保留。行业分类不作为跨公司的推导捷径。只有当前资料未形成完整路径的候选，会被标注为证据不足；这不判断现实中是否存在关联。

## 时间审查

历史查询要求路径中每一跳在截止时点有可核验的证据，同时过滤后续补充引用。此规则同样用于研发归属、产品提供和上市映射，不能因它们属于基础关系而忽略来源时间。无核实发布日期的资料以采集记录说明目前已知，不将其抓取日说成真实首次公开日，也不回填到早期事件。上市资料另保留明确的上市有效日，以区分信息公开、当前公司映射与事件时可交易证券。

DeepSeek-R1在本次入库资料下，2025-01-20、02-03、02-05分别形成0、2、4只证券的完整路径。Qwen3当前可关联摩尔线程，但2025-04尚未上市，系统没有该时点的股票事件窗口。

该回看按当前可核验的材料及其发布日期重建，未保存所有网页在历史当天的版本；它不是完整的历史信息回测数据库。

## 行情与研究产出

日线来自腾讯财经原始响应，保留请求、复权方式与CSV。以披露后首个可交易日为T0；时间仅精确到日时，保守顺延。T−1收盘为基期，1/3/5日窗口分别截至T0/T+2/T+4，各市场按自身交易日计算。基准按实际日期对齐，相对基准值是同窗口累计收益的简单百分点差。无覆盖或事件时尚未上市时说明原因，不补造价格；历史截止同时限制可见价格。

研究发现与Markdown简报来自可查询事实及上述规则，不调用模型预测股价。简报包含角色、逐跳原句、出处、历史审查与行情观察，便于从界面继续核查或导出。

## 预实验与当前边界

6段真实文本的原文与输出见[预实验说明](EXTRACTION_PILOT.md)。云接入、硬件适配及共同提及负例已逐例核对。Qwen3原输出保留了原文中的Alibaba Cloud，旧参考却使用集团实体；这项参考混合了事实抽取和集团映射，因此撤回旧汇总评分，单列复核。业务单位到上市集团的组织关系需另行提供证据。

当前交付是有限产业范围的资料快照和增量原型。后续可围绕更完整的组织层级、独立标注集、批量更新和版本追踪深化。期中不做LLM/RAG对比。
