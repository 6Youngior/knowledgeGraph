# Beamer 主题

采用 [sonnyhcl/beamerthemefdu](https://github.com/sonnyhcl/beamerthemefdu)，一个非官方的复旦大学 Beamer 主题，许可证为 Apache-2.0。

`vendor-fdu/` 保留上游主题原文件、README 和许可证。主题文件 SHA-256：

```text
493e458ec6cd955da6567c613374d2cc1faf25c51e7e21a1e5a959ddeabfa3d3
```

`main.tex` 通过 `\usetheme{fdu}` 加载主题，本地调整封面、导航、页脚、配色及字号，并取消内容页水印。未修改上游 `.sty` 文件。

`resources/fudan.pdf` 与 `resources/background.pdf` 为主题随附的校名、校徽资源，版权归复旦大学，用于本课程汇报。
