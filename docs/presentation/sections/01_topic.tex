\Intro{选题为“股票量化情报”，当前数据覆盖大模型行业相关股票。}
\begin{columns}[T,onlytextwidth]
\column{.48\textwidth}
\Head{知识组织中的问题}
\begin{itemize}
\item 技术公告中的模型、产品与证券代码分散在不同资料中。
\item 业务单位与上市集团名称不同，直接匹配容易混淆主体。
\item 适配与接入资料持续增加，当前关系不代表历史时点已知关系。
\end{itemize}
\column{.48\textwidth}
\Head{本项目的目标}
用知识图谱统一表示实体、关系及其依据\Cite{hogan2021}。
\Gap
给定产业事件与研究日期，查询：
\begin{itemize}
\item 关联证券及产业角色；
\item 事件到证券的关系路径；
\item 支持路径的原文与公开日期。
\end{itemize}
\end{columns}
