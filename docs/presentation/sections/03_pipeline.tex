\begin{frame}{知识图谱构建流程}\relax
新增资料的输入包括原文、允许的实体与关系类型，以及已有实体目录。
\par\vspace{2mm}
\begin{columns}[T,onlytextwidth]
\column{.30\textwidth}
\begin{block}{LLM 抽取}
在 Schema 约束下识别实体、关系和对应原句，生成候选结果。
\end{block}
\column{.035\textwidth}\centering\vspace{16mm}$\rightarrow$
\column{.30\textwidth}
\begin{block}{对齐与校验}
匹配已有实体；检查关系端点、来源片段和日期，形成入图预览。
\end{block}
\column{.035\textwidth}\centering\vspace{16mm}$\rightarrow$
\column{.30\textwidth}
\begin{block}{合并与查询}
按实体 ID 和事实键合并，确认后写入图谱，再查询证券路径。
\end{block}
\end{columns}
\par\vspace{3mm}
初始资料由人工整理；新增文本使用 \LiveModelName{} 抽取。当前采用 NetworkX 属性图实现存储和路径查询。
\end{frame}
