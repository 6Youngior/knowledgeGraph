\begin{frame}{知识图谱构建流程}\relax
从新增文本中抽取关系，匹配已有实体，确认后加入图谱。
\par\vspace{2mm}
\begin{columns}[T,onlytextwidth]
\column{.30\textwidth}
\begin{block}{LLM 抽取}
限定可用的实体和关系类型，提取候选关系及对应原句。
\end{block}
\column{.035\textwidth}\centering\vspace{16mm}$\rightarrow$
\column{.30\textwidth}
\begin{block}{实体对齐与检查}
按名称、别名或代码匹配已有实体，核对关系类型、原句与日期。
\end{block}
\column{.035\textwidth}\centering\vspace{16mm}$\rightarrow$
\column{.30\textwidth}
\begin{block}{合并与更新}
确认后写入图谱；重复关系合并来源，并更新关联证券查询。
\end{block}
\end{columns}
\par\vspace{3mm}
初始图谱由人工整理；新增文本使用 \LiveModelName{} 抽取，NetworkX 负责图谱存储与查询。
\end{frame}
